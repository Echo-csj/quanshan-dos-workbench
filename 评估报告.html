二、P0 · 高优先级 导航 / 视觉 / 每日操作

这一类直接决定"每天打开工作台顺不顺手"，投入小、见效快，建议优先做。

P0-1 登录/同步状态不可见

存在问题
曾出现"刷新后登录无反应"（根因是 Supabase CDN 被墙导致脚本未加载）。即便已修复，系统仍缺乏常态化的状态反馈：同步中、同步失败、最后同步时间均无提示，用户无法判断当前状态。
改进方案
顶部或侧栏底部增加全局状态条：同步中 / 成功（显示最后同步时间）/ 失败（红色）；登录失败给出明确文案而非静默无反应。
预期收益
用户随时知道系统状态，减少"以为坏了"的焦虑与重复刷新/误操作。
成本 / 影响
低成本不影响数据

P0-2 每日首屏操作路径过长

存在问题
今日指挥台聚合了信息，但"快捷操作"分散在卡片底部，常用动作（记一笔 / 新建事项 / 看预警 / 写周报）需多次跳转或滚动，开屏不能立即行动。
改进方案
今日指挥台顶部固定"今日快捷栏"：一键 新建事项 / 记一笔 / 周报草稿 / 查看预警；将"今日聚焦建议"设为默认可见（现已在下方，可上提）。
预期收益
每日高频操作步数明显下降，开屏即可行动。
成本 / 影响
低成本不影响数据

P0-3 导航冗长、移动端缺项

存在问题
侧栏 8 个入口 + 多分组；移动端底部 tab 同样偏多，模块一多就拥挤；个别入口（如联动数据）对用户意义不直观。
改进方案
按角色精简导航、常用置顶；移动端用"更多"收纳低频入口；隐藏或合并冗余入口（如将"联动数据"等低频项收进"更多"）。
预期收益
找功能更快，移动端不再拥挤，整体更克制。
成本 / 影响
中成本不影响数据

P0-4 视觉一致性 / 可读性不足

存在问题
不同模块卡片间距、空状态、数字层级不统一；数据看板数字密集无分级，涨跌配色未按中国习惯（红涨绿跌）统一，跨模块观感割裂。
改进方案
统一设计 token（间距 / 圆角 / 字号 / 空状态插画）；数字"大数突出、小数弱化"；涨跌统一红涨绿跌；统一空状态样式。
预期收益
阅读疲劳降低，关键数据一眼可见，整体更显专业。
成本 / 影响
中成本不影响数据

三、P1 · 中高优先级 打通 · 透明 · 能力恢复

P1-5 粘贴模板未与事项看板打通

存在问题
粘贴任务表格模板已具备解析能力，但解析结果未直接入库，仍需手动再录入，批量效率打了折扣。
改进方案
粘贴即解析 → 预览校验 → 一键导入事项看板（复用现有 parseTasks + 字段校验）。
预期收益
群消息/表格批量转事项效率显著提升。
成本 / 影响
中成本

P1-6 周报 / 月报口径不透明

存在问题
核心看板公式依赖 sheet1 第一列字段名，源表一旦变动易错位；用户不清楚口径从何而来，出错难定位。
改进方案
提供口径可视化面板（字段映射可配置）+ 导入时的字段校验与缺失提示。
预期收益
数据可信度提升，错位可自查自纠。
成本 / 影响
中成本

P1-7 AI 模型可能已停用（含本课表能力前置）

存在问题
设置中默认 deepseek-chat / deepseek-reasoner，而 DeepSeek 已于 2026-07-24 计划停用旧模型，现行为可能已失效；且视觉能力（本次课程表所需）尚未启用。
改进方案
模型下拉升级为 V4：deepseek-v4-flash（默认）/ deepseek-v4-pro / deepseek-v4-flash-vision-exp；增加"测试连接"与新增的"测试视觉识别"自检；课程表将复用同一把密钥实现截图识图，零额外账号成本。
预期收益
恢复并扩展 AI（周报/红绿灯/粘贴解析），并为课程表识图铺路。
成本 / 影响
低成本

四、P2 · 中优先级 规范 · 效率 · 引导

P2-8 教师字段不规范

存在问题
教师姓名在各模块可能写法不一（含/不含学科组等），关联统计易错。
改进方案
落地字段规范 + 下拉选择 / 自动补全（规范草案已有基础）。
预期收益
跨模块关联统计准确，AI 脱敏也更稳。
成本 / 影响
中成本

P2-9 缺少 ⌘K 全局搜索 / 命令面板

存在问题
找不到历史事项 / 教师 / 数据，只能逐模块翻。
改进方案
⌘K 唤起命令面板，搜索事项 / 教师 / 路由，并支持快捷跳转。
预期收益
老用户检索效率明显提升。
成本 / 影响
中成本

P2-10 空状态 / 引导缺失

存在问题
新模块（如项目组中心）首次进入无引导，新用户不知从哪下手。
改进方案
统一的空状态插画 + "下一步"指引。
预期收益
上手成本降低，首次体验更友好。
成本 / 影响
低成本

六、本次明确不做

  • 联动数据扩展：按您的要求，已不在本次范围内。
  • 课程表自动拉取：课表源站为登录墙（验证码）+ HTTP + 无 CORS，静态前端无法自动抓取，方案已否，改为"方案A 多截图 + 视觉识别"手动导入（见附录）。

附录 · 课程表模块（方案A，随本次一并实现）

作为报告建议之外本次一并交付的新模块：

  • 入口：侧栏"主功能区"新增「课程表」，移动端底部 tab 同步增加。
  • 导入：多选课表截图 → 调用同一把 DeepSeek 密钥的视觉模型（deepseek-v4-flash-vision-exp）识别 → 渲染为可编辑周网格 → 您核对修正后保存。
  • 存储：结构化网格（周一–周日 × 节次，每格含 课程/教师/教室）存于本地 localStorage，显示"上次更新时间"，支持"重新导入 / 清空"。
  • 兜底：无密钥 / 网络失败 / 识别异常时，回退到"手动填表"，不阻断使用。
